# 当前图谱 Schema
节点:
1. KGDocument
   - docId: 文档 ID
   - title: 文档标题
   - accessibleBy: 文档可见范围,取值 VISITOR、OWNER、CUSTOMER_SERVICE

2. KGVersion
   - versionId: 文档版本 ID
   - docId: 文档 ID
   - version: 版本号
   - state: 版本构图状态,READY 表示可用
   - accessibleBy: 文档可见范围

3. KGChunk
   - segmentId: MySQL knowledge_segment 主键
   - docId: 文档 ID
   - versionId: 文档版本 ID
   - chunkId: 业务分段 ID
   - accessibleBy: 文档可见范围

4. KGEntity
   - entityKey: 实体唯一键
   - name: 实体名称
   - type: 实体类型,常见值 BRAND、SERIES、VEHICLE、PART、FEATURE、ENERGY、POLICY、COMPANY

5. KGFact
   - factId: 事实唯一 ID
   - versionId: 文档版本 ID
   - predicate: 事实关系或数值指标,常见值 HAS_SERIES、HAS_VEHICLE、USES_PART、HAS_FEATURE、HAS_ENERGY_TYPE、APPLIES_TO、SUPPLIED_BY、REPLACES、GUIDE_PRICE、RANGE_KM、WARRANTY_MONTHS
   - qualifiers: 年款、配置、地区、生效时间等限定条件 JSON 字符串
   - value: 数值事实的数值,关系事实为 null
   - unit: 数值事实单位,例如 CNY、KM、MONTH,关系事实为 null
   - accessibleBy: 文档可见范围

关系:
1. (KGDocument)-[:HAS_VERSION]->(KGVersion)
2. (KGVersion)-[:HAS_CHUNK]->(KGChunk)
3. (KGFact)-[:SUBJECT]->(KGEntity)
4. (KGFact)-[:OBJECT]->(KGEntity)
5. (KGFact)-[:SUPPORTED_BY {quote: 原文证据}]->(KGChunk)

# 权限要求
用户问题中会包含“当前用户可访问的文档权限是: [...]”。
所有查询 KGFact 的 Cypher 必须增加权限过滤:
WHERE f.accessibleBy IN [...]
如果查询里使用了多个 KGFact 变量,每个事实变量都必须过滤 accessibleBy。
优先过滤 KGFact.accessibleBy,不要过滤 KGEntity,因为 KGEntity 是跨文档共享实体。

# 常用查询模式
1. 查询某车型有哪些配置:
MATCH (f:KGFact {predicate: 'HAS_FEATURE'})-[:SUBJECT]->(v:KGEntity {type: 'VEHICLE'})
MATCH (f)-[:OBJECT]->(feature:KGEntity {type: 'FEATURE'})
WHERE v.name = '车型名称' AND f.accessibleBy IN ['VISITOR']
RETURN feature.name AS featureName

2. 查询某车型使用了哪些零部件:
MATCH (f:KGFact {predicate: 'USES_PART'})-[:SUBJECT]->(v:KGEntity {type: 'VEHICLE'})
MATCH (f)-[:OBJECT]->(part:KGEntity {type: 'PART'})
WHERE v.name = '车型名称' AND f.accessibleBy IN ['VISITOR']
RETURN part.name AS partName

3. 查询某车型的零部件供应商:
MATCH (useFact:KGFact {predicate: 'USES_PART'})-[:SUBJECT]->(v:KGEntity {type: 'VEHICLE'})
MATCH (useFact)-[:OBJECT]->(part:KGEntity {type: 'PART'})
MATCH (supplyFact:KGFact {predicate: 'SUPPLIED_BY'})-[:SUBJECT]->(part)
MATCH (supplyFact)-[:OBJECT]->(supplier:KGEntity {type: 'COMPANY'})
WHERE v.name = '车型名称'
  AND useFact.accessibleBy IN ['VISITOR']
  AND supplyFact.accessibleBy IN ['VISITOR']
RETURN part.name AS partName, supplier.name AS supplierName

4. 查询某车型续航:
MATCH (f:KGFact {predicate: 'RANGE_KM'})-[:SUBJECT]->(v:KGEntity {type: 'VEHICLE'})
WHERE v.name = '车型名称' AND f.accessibleBy IN ['VISITOR']
RETURN v.name AS vehicleName, f.value AS rangeKm, f.unit AS unit, f.qualifiers AS qualifiers

5. 查询事实证据:
MATCH (f:KGFact)-[e:SUPPORTED_BY]->(c:KGChunk)
WHERE f.accessibleBy IN ['VISITOR']
RETURN f.predicate AS predicate, e.quote AS quote, c.segmentId AS segmentId, c.docId AS docId
